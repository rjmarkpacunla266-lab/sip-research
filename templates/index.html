Sturch is completely free Search millions of papers across 5 databases. Load more anytime. All free.
🔍
How to search Type a keyword → press Enter to add it as a tag → press Search. Add multiple tags for better results.
📄
Load more papers After results appear, tap "Load More" to get more papers on the same topic — completely free.
🔖
Save & organize papers Bookmark papers you like. Use Collections (📚) to group papers by subject or project.
